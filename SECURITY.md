# Política de segurança

Levamos a segurança do Netrunner Studio a sério. Use este processo para comunicar possíveis vulnerabilidades de forma responsável.

## Escopo

Esta política cobre o Netrunner Studio para Windows e os instaladores e arquivos distribuídos neste repositório.

Problemas na implementação do Studio — por exemplo, exposição indevida de tokens ou dados — fazem parte do escopo. Falhas na infraestrutura de plataformas externas, como YouTube, Twitch, Kick, TikTok, GitHub ou Cloudflare, devem ser comunicadas aos respectivos provedores.

## Versões com suporte

| Versão | Suporte de segurança |
| --- | --- |
| Versão estável mais recente em [Releases](../../releases) | ✅ |
| Versões anteriores | ❌ |

Atualize para a versão estável mais recente antes de reportar. Versões antigas podem não receber correções.

## Como reportar uma vulnerabilidade

**Não abra uma issue pública para relatar uma vulnerabilidade.**

1. Se disponível, use **Security → Report a vulnerability** neste repositório para enviar um aviso privado.
2. Se essa opção não aparecer, envie um e-mail para **netrunnerstream@gmail.com** com o assunto `Vulnerabilidade de segurança — Netrunner Studio`.

Inclua a versão do Studio, a versão do Windows, os passos para reproduzir o problema, o impacto observado e, se possível, uma demonstração segura. Remova tokens, chaves, senhas e dados pessoais de capturas e logs. Não envie credenciais.

## O que esperar

Confirmaremos o recebimento em até **5 dias úteis** e informaremos se conseguimos reproduzir o problema. O prazo de correção depende da gravidade, do impacto e da complexidade; manteremos você informado durante a análise.

Pedimos que aguarde nossa resposta antes de divulgar publicamente os detalhes, para que possamos investigar e preparar uma correção.
